# SMASH 배드민턴 마켓 - 의뢰인 미팅 자료

> **작성일:** 2026년 3월 16일
> **프로젝트:** SMASH - 배드민턴 전문 쇼핑몰
> **기술 스택:** Next.js 16 / React 19 / TypeScript / Tailwind CSS 4

---

## 1. 현재 개발 현황

### 완료된 항목 (프론트엔드 UI)

| 페이지 | 주요 기능 | 상태 |
|--------|-----------|------|
| 홈페이지 | 히어로 배너, 카테고리(7종), 베스트셀러, 신상품, 프로모션 배너 | ✅ 완료 |
| 상품 목록 | 카테고리 필터, 검색, 정렬(인기순/가격순/평점순/최신순) | ✅ 완료 |
| 상품 상세 | 이미지 갤러리, 스펙, 리뷰 수, 관련 상품, 배송 정보 | ✅ 완료 |
| 장바구니 | 수량 조절, 배송비 계산(5만원 이상 무료), 주문 요약 | ✅ 완료 |
| 아카데미 | 5개 클래스, 코치 프로필 3명, 예약 폼 | ✅ 완료 |
| 입점업체 | 5개 브랜드, 입점 신청 폼, 업체별 상품 미리보기 | ✅ 완료 |

### 미구현 항목 (백엔드 필요)

| 항목 | 설명 |
|------|------|
| 회원가입/로그인 | 소셜 로그인, 마이페이지 없음 |
| 데이터베이스 | 현재 목업 데이터만 사용 (실제 DB 없음) |
| 결제 시스템 | PG사 연동 없음 (주문 버튼은 데모) |
| 관리자 페이지 | 상품/주문/회원 관리 기능 없음 |
| 알림 시스템 | 주문확인, 배송알림 등 없음 |
| 상품 리뷰 | 평점은 표시되나 작성 기능 없음 |

## 2. 개발 로드맵 및 비용 산정

### Phase 1 — 핵심 인프라 구축 (필수)

#### 1-1. 서버/호스팅 (월 고정비)

| 옵션 | 구성 | 월 비용 | 비고 |
|------|------|---------|------|
| **A. Vercel + AWS 분리** | 프론트: Vercel Pro / 백엔드: AWS | 약 **5~8만원/월** | Vercel Pro $20 + AWS Lightsail ~3만원 |
| **B. AWS 통합** | EC2 t3.medium + RDS | 약 **8~15만원/월** | 트래픽 증가 시 비용 상승 |
| **C. NCP (네이버 클라우드)** | Micro Server + DB | 약 **5~10만원/월** | 국내 서비스, 한국어 지원 우수 |

> **권장:** 초기에는 **옵션 A** (Vercel Pro + AWS Lightsail)로 시작하여 트래픽에 따라 확장

#### 1-2. 도메인 + SSL

| 항목 | 비용 | 비고 |
|------|------|------|
| .com 도메인 | 약 **1.5~2만원/년** | 가비아, 카페24 등 |
| .kr / .co.kr 도메인 | 약 **1.4~1.8만원/년** | 카페24 첫해 30% 할인 |
| SSL 인증서 | **무료** | Let's Encrypt 또는 Vercel/AWS 기본 제공 |

> **예상 비용: 약 2만원/년**

#### 1-3. 데이터베이스 구축

| 항목 | 설명 |
|------|------|
| DB 선택 | PostgreSQL (권장) 또는 MongoDB |
| 필요 테이블 | 회원, 상품, 주문, 장바구니, 리뷰, 아카데미 예약, 입점업체 |
| 호스팅 | AWS RDS 또는 Supabase (무료 티어 가능) |

#### 1-4. 회원/인증 시스템

| 항목 | 비용 | 비고 |
|------|------|------|
| 카카오 로그인 API | **무료** | 월 쿼터 초과 시 건당 10원 |
| 네이버 로그인 API | **무료** | 네이버 검수 필요 |
| 구글 로그인 API | **무료** | OAuth 2.0 |
| 이메일 회원가입 | **무료** | 자체 구현 |

> **예상 비용: 무료** (소셜 로그인 API 모두 무료)

### Phase 2 — 결제/주문 시스템 (핵심)

#### 2-1. PG사 선택 (결제 대행)

| PG사 | 카드 수수료 | 초기 비용 | 개발 편의성 | 특징 |
|------|-----------|----------|-----------|------|
| **토스페이먼츠** | 3.4% | 가입비 무료, 연 관리비 11만원 | ⭐⭐⭐⭐⭐ | API 문서 우수, UI 세련 |
| **KG이니시스** | 1.6%~ (이벤트) | 최대 30만원 | ⭐⭐⭐ | 시장 점유율 1위, 수수료 저렴 |
| **NHN KCP** | 2.5~3.5% | 별도 문의 | ⭐⭐⭐⭐ | 안정적 운영 |
| **나이스페이먼츠** | 2.5~3.5% | 별도 문의 | ⭐⭐⭐ | 대형 쇼핑몰 다수 사용 |

> **참고:** 영세/중소 사업자는 6개월 후 매출 기준 수수료 우대 적용 가능
> **필수 선행:** 사업자등록증 + 통신판매업 신고 완료 필요

| 토스페이 | 토스페이먼츠 사용 시 기본 포함 | — |

## 3. 의뢰인 확인 필요 사항 체크리스트

### 사업/법률 관련 (의뢰인 준비 사항)

- [ ] **사업자등록증** 발급 완료 여부
- [ ] **통신판매업 신고** 완료 여부 (PG 연동 필수 조건)
- [ ] **도메인** 희망 주소 (예: smashbadminton.com, smash.co.kr 등)
- [ ] **개인정보처리방침** 및 **이용약관** 준비 (법률 검토 필요)
- [ ] **전자상거래법** 필수 표기사항 확인

### 상품/콘텐츠 관련

- [ ] **실제 상품 데이터** 제공 시점 (상품명, 가격, 이미지, 스펙)
- [ ] **상품 카테고리** 최종 확정 (현재: 라켓, 신발, 셔틀콕, 스트링, 가방, 의류, 악세서리)
- [ ] **상품 이미지** 촬영/확보 계획
- [ ] **브랜드 로고** 및 CI 자료
- [ ] **배송 정책** 확정 (무료배송 기준금액, 배송업체, 교환/반품 정책)

### 비즈니스 모델 확인

- [ ] **자사 상품만 판매** vs **멀티벤더 마켓플레이스** (입점업체 실제 운영 여부)
- [ ] 입점업체 **수수료/정산 구조** (마켓플레이스인 경우)
- [ ] **아카데미 예약 시스템** 실제 운영 범위 (단순 문의폼 vs 온라인 결제 예약)
- [ ] **쿠폰/프로모션** 시스템 필요 여부

### 결제/정산 관련

- [ ] **선호 PG사** 선택 (토스페이먼츠 vs KG이니시스 vs 기타)
- [ ] **필요 결제 수단** (카드, 계좌이체, 카카오페이, 네이버페이 등)
- [ ] **정산 주기** 희망 (주간/월간)

### 기타 기능

- [ ] **관리자 페이지** 필요 기능 범위
- [ ] **상품 리뷰** 기능 필요 여부
- [ ] **위시리스트** 기능 필요 여부
- [ ] **재고 관리** 방식 (자동/수동)
- [ ] **배송 추적** 연동 여부

## 5. 개발 우선순위 제안

```
[1단계 - MVP 런칭] ━━━━━━━━━━━━━━━━━━━━━━━━
  ├── DB 구축 + 백엔드 API 개발
  ├── 회원가입/로그인 (카카오, 네이버)
  ├── 실제 상품 데이터 연동
  ├── 결제 시스템 (PG 연동)
  └── 주문/배송 관리 기본 기능

[2단계 - 운영 안정화] ━━━━━━━━━━━━━━━━━━━━━━
  ├── 관리자 페이지 (상품/주문/회원 관리)
  ├── 마이페이지 (주문내역, 배송조회)
  ├── 알림톡 연동 (주문확인, 배송알림)
  └── 아카데미 예약 + 결제 연동

[3단계 - 기능 확장] ━━━━━━━━━━━━━━━━━━━━━━━
  ├── 상품 리뷰/평점 시스템
  ├── 위시리스트
  ├── 쿠폰/프로모션 시스템
  ├── 입점업체 관리 대시보드 (마켓플레이스 시)
  └── SEO 최적화 + 네이버 검색 연동
```

## 6. 미팅 시 논의 순서 제안

1. **현재 개발 상태 시연** — 완성된 UI 보여주기 (localhost 또는 배포 URL)
2. **사업 준비 현황 확인** — 사업자등록, 통신판매업 신고 등
3. **비즈니스 모델 확정** — 자사몰 vs 마켓플레이스, 아카데미 운영 범위
4. **우선순위 합의** — Phase 1 범위 확정
5. **PG사 선택** — 비용 vs 개발 편의성 트레이드오프 설명
6. **일정 조율** — Phase 1 런칭 목표일
7. **상품 데이터 확보 계획** — 이미지, 가격, 스펙 제공 시점
8. **월 운영비 안내** — 매출 구간별 예상 비용 공유
